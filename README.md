# Invitación del bautizo de Xavier Mael

Vista temporal para revisar la invitación desde teléfonos y otros dispositivos.

## Alcance de esta prueba
- Diseño, fotos, calendario, cuenta regresiva y enlaces de Google Maps.
- Formularios desactivados: GitHub Pages no ejecuta el servidor PHP.
- La versión completa con Google Sheets se conserva en XAMPP.

Edita `evento.js` para cambiar datos e imágenes. La hora de 13:00 del 2 de enero de 2027 es provisional.
No se incluyen credenciales, código de acceso a Google Sheets ni mensajes de invitados.
